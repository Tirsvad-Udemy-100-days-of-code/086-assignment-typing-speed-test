# Typing Speed Test

Aplikasi desktop kecil yang menguji kelajuan anda menaip: ia menunjukkan teks contoh, mengukur masa semasa anda menaipnya dan melaporkan perkataan seminit serta ketepatan anda. Ini ialah tugasan Hari ke-86 kursus Udemy "100 Days of Code: The Complete Python Pro Bootcamp", dibina dalam empat langkah. Setiap langkah mempunyai satu halaman dengan tangkapan skrin dan bahagian tentang apa yang kita pelajari.

| Halaman | Baca apabila anda mahu |
| --- | --- |
| [Persediaan](Setup-ms) | mencipta `.venv` setempat, memasang projek, menjalankan program dan ujian |
| [Langkah 1: tetingkap dan teks contoh](Step-1-Window-And-Text-ms) | lihat apa yang dibina langkah 1 |

Halaman langkah ditambah apabila setiap langkah dibina. Kod sumber, fail README dan dokumen projek berada dalam repositori.
