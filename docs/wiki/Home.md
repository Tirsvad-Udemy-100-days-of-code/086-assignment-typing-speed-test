# Typing Speed Test

A small desktop application that tests how fast you type: it shows a sample text, times you while you type it and reports your words per minute and accuracy. It is the Day 86 assignment of the Udemy course "100 Days of Code: The Complete Python Pro Bootcamp", built in four steps. Each step has a page with a screenshot and a section on what the step taught.

| Page | Read it when you want to |
| --- | --- |
| [Setup](Setup) | create a local `.venv`, install the project, run the program and the tests |

The step pages are added as each step is built. The source, the README and the project documents are in the repository.
